왼쪽: 구름 셰이더 출력(mode=1). 오른쪽: 입력 이진 원본. 둘을 비교해 경계 지글거림·가독성을 본다.
흰=den +2.2 / 검정=den −2.0 (값 범위의 양끝 — billow 진폭 ±0.625를 안쪽에서 압도하는 동작점). 프리셋은 구름색 전부 흰, 하늘 전부 흰(far 퇴색 무력화), rim 0.

판정 포인트:
  1. 정지 text가 깨끗이 읽히는지 (안쪽은 billow에 면역 — 수치상 보장, 경계만 ±0.27 texel 흔들림).
  2. scale 12 ↔ 2 전환 시 경계 물결 파장이 어떻게 바뀌는지 (클수록 잘게 지글거림).
  3. 시간 흐름 모드에서 정지 화면이 끓는지 (uTime worley wobble — 동영상에선 꺼야 함).
  4. 해상도를 올리면 경계 회색대(1 texel 보간)가 상대적으로 얇아지는지.
  5. FPS: 풀스크린 bake 1회당 ms — 실제 장면 통합 시 s(굽기 배율) 결정 근거.
실장면 통합 시 남은 작업(본 파일과 무관): 하늘 팔레트 흑화(투명 배경 뒤 비침), 오버레이 제거(BLOOM/DY_LIGHT/DC_LIGHT/반짝임/별/달/토리이/랜턴), 프레임마다 upload('den') + render() 호출 배선 — CloudDoc.bake()는 같은 doc 객체면 업로드를 건너뛰므로(bakeDoc !== doc 가드) 재사용 불가, 렌더러 직접 호출 필요.
